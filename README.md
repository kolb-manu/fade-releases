# Fade releases

This repository holds **only release files** for the Fade Minecraft client. There is no code here.

- **Fade Launcher** installers: releases named `launcher-vX.Y.Z`
- **Fade** (the mod) jars: releases named `fade-vX.Y.Z`

Download the newest launcher from the [Releases page](../../releases). The launcher updates Fade (and itself) from here.
